# نظام نبض (Nabd) للمراقبة والتشخيص اللحظي ⚙️

## نبذة عن المشروع
مشروع "نبض" هو نظام أنظمة مدمجة (Embedded Systems) متكامل للمراقبة والتشخيص اللحظي للمحركات والآلات الصناعية والصيانة التنبؤية (Predictive Maintenance). يقرأ النظام بيانات الاهتزاز بشكل دقيق لاكتشاف أي خلل أو خطر مبكر في الآلة، ويقوم بإيقاف النظام تلقائياً عند تجاوز الاهتزاز للحد المسموح لحماية المعدات، مع إطلاق إنذار صوتي وضوئي.

يتكون المشروع من:
* **متحكم Arduino وحساسات:** لمعالجة بيانات الاهتزاز الأولية.
* **متحكم PIC16F877A:** للتحكم المباشر في دائرة الفصل (Relay)، شاشة LCD، والإنذارات.
* **واجهة SCADA (بواسطة Python Tkinter):** لوحة تحكم تفاعلية تعرض حالة الاهتزاز برسم بياني لحظي، وتقوم بتجميد الإشارة وتحديدها باللون الأحمر عند التقاط خطر.
